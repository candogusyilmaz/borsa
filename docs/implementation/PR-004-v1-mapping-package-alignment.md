# PR-004 — V1 mapping package alignment

Status: **ACTIVE**

## Goal

Move the ten JPA mapping and repository types accepted in PR-003 into the authoritative capability sub-packages and replace handwritten entity accessor/constructor boilerplate with the accepted Lombok annotations, without changing persistence mappings, repository behavior, database structure, or API behavior.

This is a deliberately mechanical prerequisite for local authentication. It keeps the next behavioral PR focused on registration rather than mixing package moves and mapping cleanup with new write semantics.
